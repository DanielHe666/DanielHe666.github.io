概览

MedAgt 是一个面向远程问诊场景的智能医学站点 Demo：前端采集症状与基本信息，后端通过 DeepSeek 多 Agent + PubMed/NICE 检索管线生成“可追溯”的初步建议（triage、建议、后续行动、追问、证据链）。

重要说明：本项目用于演示工程与检索/推理流程，不构成医疗建议；请勿用于真实诊疗决策。

我做了什么

  • 搭建前后端完整链路：前端表单采集 → 后端分析接口 → 输出结构化结果与证据链
  • 设计并实现“检索增强 + 多智能体协作”的分析流程，支持追问闭环与进度追踪
  • 工程化部署落地：提供一键部署脚本，并给出 Ubuntu（systemd + Nginx 反代）的部署形态

技术要点

  • 前端：Next.js（App Router）+ TypeScript；交互覆盖多病例管理、进度跟踪、证据下载与轻量可视化
  • 后端：FastAPI + Pydantic + httpx；提供健康检查与分析接口（/health、/api/v1/analyze）
  • 证据来源：PubMed（NCBI E-utilities）、NICE Guidelines；强调“可追溯”证据链输出
