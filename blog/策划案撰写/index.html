《“巧手时光·定格温暖”干花相框制作活动策划案》 。

📋 活动策划案概要

  • 活动名称：巧手时光·定格温暖——40分钟干花相框制作沙龙
  • 活动主题：以手工为媒，以陪伴为核，共创温馨记忆
  • 活动时长：40分钟
  • 活动形式：一对一结对（1名同学陪伴1位长者），协作完成
  • 核心目标：
    1. 情感目标：在协作中完成一次深度交流与陪伴。
    2. 成果目标：共同制作一个完整的、可带回家的干花相框。

🛒 物资准备清单（按10组准备）

类别物品名称规格/数量备注
核心材料空白木质相框10个A5尺寸（约15*21cm），活动前需全部拆封，取出玻璃和背板。
彩色卡纸10-12张作为衬底，多备几种颜色供选择。
混合干花材料包1大包包含各色压花、配叶、满天星等。提前分装至10个小碟子或纸杯中，避免混乱。
工具与辅料手工白乳胶10瓶比胶棒更稳固。确保瓶口通畅。
一次性乳胶管/棉签20根用于精确涂胶，避免弄脏手和作品。
小镊子10个方便夹取细小干花。
装饰丝带/小珍珠少量增加作品层次感，非必需。
现场用品桌布10张保护桌面，便于清理。
湿纸巾/抹布2包随时清洁溢出的胶水。
签到表、笔1套
相机/手机2部指定同学负责全程拍照。
轻音乐播放设备1套活动前、中播放舒缓纯音乐。

⏰ 40分钟超详细流程表

时间段环节名称核心任务与操作细节负责人/话术示例
0-5分钟快速破冰·结对入座1. 音乐暖场：活动开始前即播放舒缓轻音乐。
2. 高效结对：同学在门口迎接，直接引导长者到座位，实现“一对一”结对。
3. 简单问候：“爷爷/奶奶您好，我是小王，今天由我陪您一起做手工。”		全体同学
话术：“我们来一起做个漂亮的相框带回家吧！”
5-10分钟演示启动·激发灵感1. 主持人开场：简短欢迎，介绍活动目标——共同创作一个独一无二的相框。
2. 成品展示：快速展示2-3个成品样例，激发兴趣。
3. 关键步骤演示：只演示核心三步：①选衬纸；②摆造型（不粘）；③涂胶固定。强调“先摆后粘”。		主持人
话术：“大家先想好怎么摆最漂亮，确定好了我们再粘，不用急哦！”
10-30分钟核心制作·温情相伴1. 选择材料：协助长者选择喜欢的卡纸和干花。
2. 布局设计（5分钟）：鼓励长者在衬纸上摆放干花，此阶段是交流黄金时间。
3. 粘贴固定（15分钟）：同学协助涂胶，长者按压固定。使用棉签/乳胶管精确控制胶量。
4. 机动支援：支援组巡视，帮助解决困难，补给物料。		结对同学
互动话术：“这片叶子放这里真好看！”“这朵小花就像为您今天的心情开放的。”
30-35分钟成果展示·分享喜悦1. 快速展示：邀请2-3位意犹未尽的长者简短展示（每人20秒），或请所有长者将作品举高。
2. 集体赞美：无论是否发言，对每一件作品都报以热烈掌声。		主持人
话术：“大家的作品太美了！每一件都是独一无二的艺术品！”
35-40分钟合影留念·温馨告别1. 大合影：全体手持自己的作品，齐声说“温暖定格！”并合影。
2. 协助清理：同学帮长者将相框装入包装袋，清理桌面，并送至门口道别。
3. 物料整理：团队快速收拾现场。		摄影组、全体同学
话术：“爷爷/奶奶，您做的真棒！欢迎下次再来参加我们的活动！”

👥 团队分工与执行要点

角色核心职责
总负责人 (1人)全局把控，确保各环节无缝衔接，尤其注意控制时间。
主持人 (1人)串场、控时，语言简洁明快，富有感染力。
机动支援组 (2人)提前分装好所有材料包。活动中巡视，提供“救火”支援（如补胶水、解决困难）。
摄影记录组 (1-2人)关键角色。必须主动抓拍，确保捕捉到每位长者的特写笑脸和互动瞬间。

执行要点提醒：

  • 节奏是生命线：主持人必须严格计时，防止在“布局设计”环节耗时过长。
  • 准备大于一切：所有材料必须在活动前分装、拆封完毕，做到“开箱即用”。
  • 安全第一：提醒大家小心使用白乳胶，如不慎沾上，用湿纸巾及时擦拭。
