git

本文介绍了使用 Git rebase 进行分支合并的解决方案，帮助开发者保持线性清晰的提交历史。读者将学会如何安全地执行 rebase 操作，包括查看分支状态、处理冲突及完成推送。亮点在于通过 fetch、rebase 和冲突解决步骤，有效避免合并混乱，提升版本管理效率。

git merge solution

1.查看当前分支

git branch --show-current

2.看有哪些未推送/未拉取

git fetch origin
git status
git log --oneline --decorate --graph --all | head -20

安全解决（rebase保持线性历史）

git fetch origin
git pull --rebase origin main

出现冲突

git add <冲突文件...>
git rebase --continue

rebase结束

git push origin main
