概览

AutoBlog 是一个轻量级静态博客生成器：把 source/ 中的 Markdown 构建为可部署的静态站点（public/），并支持一条命令部署到 GitHub Pages。

我做了什么

  • 设计并实现“Markdown → 静态站点”的构建流水线与站点模板
  • 补齐常用博客能力：标签/归档、站内搜索、RSS 与 sitemap
  • 提供桌面端编辑器（PySide6）：编辑配置、实时预览、点击构建与本地预览服务

技术要点

  • Python 构建器：将内容解析、模板渲染、资源拷贝与输出目录组织为可维护的流水线
  • 可部署性：生成物适配 GitHub Pages 托管；提供 deploy 脚本降低上线成本
  • 桌面端：复用构建逻辑，提供“配置/文章/主题”的一站式管理与预览
