常见问题

快速了解上线前的最后疑问

需要服务器或数据库吗？

不需要。AutoBlog 输出纯静态文件，可直接托管到 GitHub Pages、Vercel、Netlify 等平台。

可以关闭或替换 AI 摘要吗？

可以。在 config.yaml 中切换参数即可关闭智能摘要或替换模型、温度与输出长度。

主题可以自定义吗？

可以。AutoBlog 使用统一的 CSS 变量，修改颜色、圆角、阴影即可立即获得新主题。
